# 🚀 خطتي لتطوير مهارات هندسة البرمجيات

> ملف متابعة مشترك بيني وبين Claude. كل ما نتفق عليه، وكل تقدم نحرزه، نسجله هنا.

---

## 👤 نبذة

- طالب هندسة معلوماتية (سنة رابعة) في الجامعة الافتراضية السورية
- أعيش في طرطوس، سوريا
- **الهدف:** التأهل للعمل الحر والوظائف البرمجية، وبناء مصادر دخل متعددة خلال وقت قصير
- **تخصصي المفضل:** الأنظمة الإلكترونية وتطبيقات سطح المكتب
- **الستاك الحالي:** React, JavaScript, Python, Java, Electron, SQLite

## 📏 قواعد العمل

1. **أكتب أولاً بنفسي** ثم أطلب المراجعة (محاولة 20–30 دقيقة قبل السؤال).
2. الذكاء الاصطناعي **معلّم ومراجِع**، لا كاتب للحل الكامل.
3. **لا أنسخ سطراً لا أستطيع شرحه.** إن حدث ذلك، أطلب الشرح ثم أعيد كتابته بيدي.
4. اختبار أسبوعي: أبني شيئاً صغيراً من الصفر بدون مساعدة.
5. أرفع تمارين اليوم إلى المستودع يومياً، ولو كانت بسيطة.
6. يوم راحة واحد أسبوعياً.
